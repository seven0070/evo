# Changelog

## 1.0.0 — Evo V1

Evo V1 freezes the Phase 1–20 capability set and adds repository-wide integration hardening rather than another architectural layer. The release validates Cognitive, Memory, World, Capability, Model, Specialist, External Integration, Runtime, Kernel, Verification, Experience, Evaluation, Self-Model, Learning, Evolution, Metamorphosis, Sandbox, Benchmark, Promotion, and Rollback integration through their existing authority boundaries.

This release adds deterministic SQLite integrity and persisted-payload validation during Runtime startup, bounded event payload envelopes, fail-closed corrupted-state recovery, reproducible offline release validation, stable package metadata, operational documentation, and focused hardening tests. It retains local-first offline execution, exact approval scope, workspace confinement, shell restrictions, protected-core integrity, production immutability, bounded resource usage, restart recovery, native rollback, and explicit human control.

No autonomous approval, promotion, deployment, unrestricted self-modification, arbitrary code execution, credential acquisition, arbitrary plugin installation, production mutation, protected-authority mutation, uncontrolled agent spawning, uncontrolled reflection loop, replication, or new Phase 21 architectural layer is included.
